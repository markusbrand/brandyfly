# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's security
advisory feature for this repository. Do not open a public issue containing
exploit details, credentials, private location data, or other sensitive data.

## Supported versions

BrandyFly has not published a supported release yet. Security fixes currently
target the default branch.

## Sensitive data

Flight tracks and live positions are location data. Test fixtures must be
synthetic or explicitly anonymized. Production credentials and signing keys
must be supplied outside the repository.
