# XContest source review

Reviewed official public materials:

- XContest homepage: `https://www.xcontest.org/world/en/`
- XContest FAQ: `https://www.xcontest.org/world/en/faq/`
- XContest privacy policy: `https://www.xcontest.org/world/en/privacy-policy/`
- XContest live flights page: `https://www.xcontest.org/world/en/flights/live/`

Key findings:

- XContest describes upload via the XCTrack Android app.
- Public contact addresses are `support@xcontest.org`, `xctrack@xcontest.org`,
  and `info@xcontest.org`.
- The privacy policy says XContest collects GPS tracklogs and livetracking data,
  keeps personal information for up to 90 days after account termination unless
  longer retention is required, and asks users to review third-party policies.
- No public upload or catalogue API documentation was found in the reviewed
  materials.
- No written permission for BrandyFly-specific upload or catalogue access was
  found in the reviewed materials.

Review date: 2026-08-07
