# XContest evidence checklists

## Upload

- [ ] Official upload interface or written permission identified
- [ ] Authentication method and credential lifecycle documented
- [ ] Request/response contract covers success, duplicate, retryable failure, and permanent failure
- [ ] Consent, retention, attribution, and redistribution terms documented
- [ ] Rate limits and caching constraints documented
- [ ] Test data is synthetic or explicitly approved
- [ ] No credentials, sessions, or private flight locations appear in logs or fixtures

## Catalogue

- [ ] Official catalogue interface or written permission identified
- [ ] Authentication method and credential lifecycle documented
- [ ] Pagination, filtering, and incremental retrieval rules documented
- [ ] Rate limits, caching, and redistribution terms documented
- [ ] 08:00 `Europe/Vienna` schedule confirmed or an approved alternative recorded
- [ ] Test data is synthetic or redacted
- [ ] No credentials, sessions, or private flight locations appear in logs or fixtures
